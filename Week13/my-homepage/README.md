# My Homepage

A responsive personal homepage built with **React** and **Vite**.

## Live URL

https://YOUR-SITE.vercel.app  <!-- replace with your real link after deploying -->

## Features

- Semantic HTML: header, nav, main, footer
- Sections: Hero, Projects, Skills, Contact
- Responsive layout (works on phones)
- Images with alt text
- Auto deploy on every push to `main`

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
