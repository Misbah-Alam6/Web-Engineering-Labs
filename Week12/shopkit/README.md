# ShopKit - React UI Library Homepage

**UI Library:** React Bootstrap

**Installation Command:** `npm install react-bootstrap bootstrap`

**Project:** A responsive online shopping homepage built using React and React Bootstrap.

**Components:** Navbar, Hero, Features, and Footer.

**Benefits:** React Bootstrap provided ready-made Navbar, Button, Container, Card, Row, and Col components, saving time and reducing the need to build these UI elements manually.

**Build Command:** `npm run build`
